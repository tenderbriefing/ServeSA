# Municipal User Guide — ServeSA Ops

## What this is

A daily workspace for municipal officials — closer to an issue tracker than an admin dashboard.

## Pages

1. **Dashboard** — today’s queues (mine, unassigned, urgent, awaiting ack, in progress, resolved, triage).
2. **Cases** — searchable/filterable list for your municipality.
3. **Case** — description, map link, assignment, timeline, internal notes, public updates, one primary action.
4. **Team** — officials and departments with open workload.
5. **Settings** — departments and category routing.

## Processing a case

Acknowledge → Assign (department, optional official) → Start Work → Resolve (summary required) → Close.

If routing is pending or triage is set, assign is blocked until municipality GIS routing succeeds.

## Visibility

- **Internal notes** — staff only.
- **Public updates** — visible to the reporting citizen.
- Never invent ward/municipality values; GIS remains authoritative.
